# 📝 To-Do App

A modern desktop To-Do application built with **Python** and **CustomTkinter**.

## 🚀 Features

- ✅ Add Tasks
- ✏️ Edit Tasks
- 🗑️ Delete Tasks
- ✔️ Mark Tasks as Completed
- ↩️ Undo Completed Tasks
- 📅 Due Date Picker
- ⭐ Priority Levels (High, Medium, Low)
- 🔍 Search Tasks
- 🌙 Dark / Light Mode
- 💾 Automatic JSON Storage
- 📊 Dashboard (Total, Pending, Completed, Due Today)

---

## 🛠️ Technologies Used

- Python 3
- CustomTkinter
- tkcalendar
- JSON

todo-app/

## 📦 Installation

Install dependencies:

```bash
pip install customtkinter tkcalendar
```

Run the project:

```bash
python main.py
```
